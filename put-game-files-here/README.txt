Xenoblade Chronicles 2 on Android - put your game files here
============================================================

Put these into this folder (any file names are fine):

  1. the base game     title 0100E95004038000  v0         NSP, NSZ, XCI or XCZ
  2. update 2.1.0      title 0100E95004038800  v983040    NSP, NSZ, XCI or XCZ
  3. prod.keys         the keys of YOUR OWN console
  4. optional: DLC files (their content was not tested)

Then, one folder up, run:   ./setup.sh

Your files are only read. They are linked into the work folder, not copied, and nothing is uploaded.
Everything in this folder except this README is ignored by Git: never commit game files or keys.
Dump the game and the keys from a Switch you own; they are never shared by this project.
